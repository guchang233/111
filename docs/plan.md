# 《把一首歌拆到只剩数字》制作方案

> 状态：风格板阶段。画面语言已出图（见 `styleboard/`），等待音频文件与片段时间点。

## 一句话

三首 Animenz 钢琴改编，一层层拆开：声部、节奏、和弦、音高、音色，最后只剩一条正弦波和一张零件清单；
然后全部拼回去。数字能拆开一首歌，却拆不出你为什么会被它打动。

## 音乐

| 段落 | 曲目（钢琴改编：Animenz） | 负责拆的层 | 题词 |
| --- | --- | --- | --- |
| 开场 + 第一段 | 《残酷天使的行动纲领》开头（EVA） | 声部、节奏 | 「歌真是好东西啊。」——渚薰 |
| 第二段（戏剧中心） | 《Sincerely》（紫罗兰永恒花园 OP） | 和弦、音高（¹²√2、朱载堉） | 「我想知道'我爱你'是什么意思。」——薇尔莉特 |
| 第三段 + 拼回 | 《葬送的芙莉莲》组曲 | 音色 → 正弦波 → 零件清单 | 「为什么我没有想着，多了解他一点呢。」——芙莉莲 |

三部作品讲的都是"理解感情"，正好接上结尾。

## 结构（约 3 分半）

1. **开场**：EVA 开头直接响起，暗场；主标题卡（EVA 粗明朝体致敬）。
2. **LAYER 01 声部**：爆炸图把钢琴拆成旋律 / 和声 / 低音 / 时值四个零件。
3. **LAYER 02 节奏**：速度、切分、拍子的对半切分；欧几里得节奏。
4. **LAYER 03 和弦**：4:5:6，利萨茹图形让和谐"看得见"。
5. **LAYER 04 音高**：毕达哥拉斯音差 → 奇偶证明 → 朱载堉 ¹²√2（打字机逐字打出）→ 钢琴上的大三和弦其实是 4 : 5.04 : 5.99，图形开始缓慢转动，转速等于拍音。
6. **LAYER 05 音色**：泛音 → 傅里叶 → 一组旋转的圆（芙莉莲的魔法阵）。
7. **LAYER 06 波**：只剩一条正弦波，然后静音。
8. **零件清单**：八个零件，第八个是"打动你的那部分——无法拆解"。
9. **拼回去**：零件飞回原位，芙莉莲的旋律完整响起。莱布尼茨：「音乐，是心灵在不知不觉中进行的计数。」

## 设计系统

- **三种场景色**：墨黑 `#0b0b0c`（情绪段）、象牙纸 `#ece7dd`（拆解说明书段）、夜色渐变（芙莉莲段）。
- **每段一个点缀色，只用在极少数地方**：EVA 警示橙 `#e8502e`、薇尔莉特胸针祖母绿 `#2f7d62`、芙莉莲淡金 `#cdb986`；全片通用的工程师红笔 `#c3402e`。
- **字体（全部 SIL OFL，可商用）**：思源宋体 Noto Serif SC（中文）、Cormorant Garamond（英文衬线）、IBM Plex Mono（数据标注）、Courier Prime（打字机）。
- **原则**：画面不出现任何动画截图或角色；一帧只讲一件事；所有波形和图形都由真实声音数据生成（所见即所闻）；全片叠极轻胶片颗粒，压住 B站转码后的暗部色带。
