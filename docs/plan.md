# 《把三首歌拆到只剩数字》制作方案

> 状态：全片 1080p 初版已渲染；终版 4K、封面与 B站资料见 `docs/bilibili.md`。

## 一句话

把 Animenz 改编的三首动漫钢琴曲一层层拆开：声部、节奏、和弦、音高、音色，直到只剩一条正弦波和一张零件清单，然后拼回去。
数字能拆开一首歌，却拆不出你为什么会被它打动。

## 设计系统

- **场景底色**：墨黑 `#0b0b0c`（情绪段）、象牙纸 `#ece7dd`（拆解说明书段）、夜色渐变（芙莉莲段）
- **每段一个点缀色**：EVA 警示橙 `#e8502e`、薇尔莉特祖母绿 `#2f7d62`、芙莉莲淡金 `#cdb986`，全片通用工程师红笔 `#c3402e`
- **字体（SIL OFL）**：思源宋体、Cormorant Garamond、IBM Plex Mono、Courier Prime
- **原则**：不出现任何动画截图；一帧只讲一件事；所有图形由真实数据生成（所见即所闻）；颗粒在编码时叠加，压住 B站转码后的暗部色带

## 声音

- 钢琴：Salamander Grand Piano V3（Yamaha C5，16 力度层，CC BY 3.0），自写 SFZ 采样器，按和声自动踩踏板，合成厅堂混响
- 声音设计：节拍器、五度音、毕达哥拉斯音差拍音、打字机键、平均律闭合、纯律与平均律和弦、A4 加法合成，全部与画面共用一条时间轴
- 响度：−15 LUFS，真峰值 −1.5 dBTP

## 管线

```
assets/midi/*.mid ──► scripts/build_data.py ──► film/data/*.json ──► film/ (浏览器场景) ──► render/render-film.mjs ──► mp4
                  └─► scripts/build_audio.py ──► out/audio/master.wav ───────────────────────────────┘
```

```bash
cd scripts && python3 build_data.py && python3 build_audio.py && cd ..
node render/render-film.mjs --scale 1 --out out/film/draft.mp4              # 1080p 初版
node render/render-film.mjs --scale 2 --crf 16 --out out/film/final-4k.mp4  # 4K 终版
```

MIDI 与由其导出的音符数据不进仓库。
