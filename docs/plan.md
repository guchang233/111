# 《把三首歌拆到只剩数字》制作方案

> 状态：v3（音乐展示版）。去掉了白底讲解段，片段从 4 个增加到 7 个。终版 4K、封面与 B站资料见 `docs/bilibili.md`。

## 一句话

Animenz 改编的三首动漫钢琴曲，选了七个片段，全片 3 分 49 秒。
画面里的每一个点、每一条线、每一朵花都对应一个真实的音符：出现在它被弹响的那一刻，高度是音高，大小是力度，所见即所闻。
数字能写下一首歌的每一个音，却写不下你为什么会被它打动。

## 设计系统

- **场景底色**：墨黑 `#0b0b0c`（EVA、Sincerely）、夜色渐变（芙莉莲）
- **每个乐章一个点缀色**：EVA 警示橙 `#e8502e`、薇尔莉特祖母绿 `#2f7d62`、芙莉莲淡金 `#cdb986` 加苍月草淡蓝 `#d6e1f0`
- **字体（SIL OFL）**：思源宋体、Cormorant Garamond、IBM Plex Mono、Courier Prime
- **原则**：
  - 不出现任何动画截图
  - 不讲解，只展示
  - 所有图形都由真实音符生成
  - 颗粒在编码时叠加，压住 B站转码后暗部的色带

## 声音

- **钢琴**：Salamander Grand Piano V3（Yamaha C5，16 个力度层，CC BY 3.0），用自写的 SFZ 采样器演奏，带释音采样，同一个键重击时切断前一个音
- **踏板**：MIDI 里的原始踏板数据不可用，改为按和声自动踩踏板
- **混响**：合成的厅堂混响
- **衔接**：片段之间按乐句无缝衔接或留白；接缝处提前抬踏板，避免和弦糊在一起
- **响度**：−15 LUFS，真峰值 −1.5 dBTP，响度范围（LRA）11.8 LU

## 管线

```
assets/midi/*.mid ──► scripts/build_data.py ──► film/data/*.json ──► film/ (浏览器场景) ──► render/render-film.mjs ──► mp4
                  └─► scripts/build_audio.py ──► out/audio/master.wav ───────────────────────────────┘
```

```bash
cd scripts && python3 build_data.py && python3 build_audio.py && cd ..
node render/render-film.mjs --workers 4 --grain 3 --crf 20 --out out/film/draft.mp4                 # 1080p 初版
node render/render-film.mjs --workers 4 --scale 2 --grain 4 --crf 16 --out out/film/final-4k.mp4    # 4K 终版
node render/film-stills.mjs 40 135 166 --only atfield,flowers,magic                                  # 单帧检查
SCALE=1 node render/render-stills.mjs render/covers/cover-16x9.html render/covers/cover-4x3.html    # 封面
```

MIDI 和由 MIDI 导出的音符数据都不进仓库。
